## （2）遇到的问题与解决方式

1. **负利率只判断一次，程序仍会继续往下算。**
   一开始只用一个 `if rate < 0:` 提示一次，提示完程序照样用负利率计算。改为 `while True` 循环：输入不合法就 `continue` 重新提示，直到读到非负利率才 `break`，拦截才真正有效。

2. **输入字母（如 abc）时程序直接崩溃。**
   `float("abc")` 会抛 `ValueError`。用 `try/except ValueError` 包住转换语句，捕获后提示“输入不是有效数字”并重新输入，程序不再中断。

3. **金额显示出现一长串小数（如 11576.250000000002）。**
   浮点幂运算有二进制舍入误差。统一用 `%.2f`（或 `round(x, 2)`）按“分”保留两位小数，输出与检查点完全一致；同时我在验证时用独立算式复算，避免只看程序自己的输出。

4. **（扩展实践中的前端问题）资金构成条不显示颜色。**
   在做网页版计算器时，flex 容器内色块设置 `height:100%` 被解析为 0。经查 CSS 规范，flex 子项的百分比高度在未显式拉伸时会塌陷，改用 `align-items:stretch` + `align-self:stretch` 后正常显示。
